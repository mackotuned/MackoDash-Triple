# Honda emblem source

`honda_classic_car_logo.png` is a 250 px raster rendering of
[`Honda.svg`](https://commons.wikimedia.org/wiki/File:Honda.svg) from Wikimedia
Commons. The file page identifies it as a public-domain simple geometric/text
logo and notes that the Honda mark remains protected as a trademark.

`main/honda_emblem.c` contains a 150 px, 2-bit alpha mask generated from this
source for the controller screensaver.
